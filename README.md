# webgm
A simple app to help solo ttrpg players, a GM Emulator.
The progressive web app can be found [here](https://samelinux.github.io/webgm/)

The main goal is to provide a single place to:
- have a simple yes/no oracle; ! means "and", ? means "but"
- roll all major dices (d4,d6,d8,d10,d20,d100) and standards cards
- have a basic difficulty generator (a gaussian distribution from 1 to 10 so you can adapt it to your system!)
- randomize names
- randomize adjectives (for objects, npc, places, ...)
- randomize objects (to generate loot for example)
- randomize a color (you never know when you'll ned one!)
- randomize pc and npc wants, personality and psychosis
- randomize png jobs
- randomize allies and enemies action in combat
- randomize places
- have a quest spark randomizer
- have a dungeon or building generator (rooms size, exits, condition, content and encounter)
- have a star system generatore (stars, planets, anomalies, spices, evolution and relationship)
- have an icon randomizer (to spice things up)
- have a simple market multiplier generator based on specie relationship)

## Themes
All these generator have (or try to have) 4 themes: Fantasy, Modern, Scifi, Post-apocalyptic.
You can adapt each value to your settings, otherwise, just roll again!

## How to use it
Just tap on the screen/click with the mouse/press any key to roll new values.
The progressive web application can be installed on your device's home making it basically an app.
Once added to your home (or desktop if you're on pc) it should cache all file and work offline too!
