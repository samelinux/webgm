# webgm
A simple app to help solo ttrpg players, a GM Emulator.
The progressive web app can be found [here](https://samelinux.github.io/webgm/)

The main goal is to provide a single place to:
- have a simple yes/no oracle; ! means critical (aka and), ? means "failure" (aka but)
- roll all major dices (d4,d6,d8,d10,d20,d100)
- have a basic difficulty generator (a gaussian distribution from 1 to 10 so you can adapt it to your system!)
- randomize objects (to generate loot for example)
- randomize a color (you never know when you'll ned one!)
- randomize the base of a friendly(?) npc encounter
- have an hostiles (?) encounter generator
- have a place generator if your quests need one
- have a quest sparker so you can dive right into your adventures
- randomize adjective to chain to every randomizer above
- randomize png/npc/things/beings names

## Themes
All these generator have 4 themes: Fantasy, Modern, Scifi, Post-apocalyptic.
You can adapt each value to your settings, otherwise, just roll again!

## How to use it
Just tap on the screen/click with the mouse/press any key to roll new values.
The progressive web application can be installed on your device's home making it basically an app.
Once added to your home (or desktop if you're on pc) it should cache all file and work offline too!
